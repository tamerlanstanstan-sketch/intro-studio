# Интро Студия: сайт для GitHub Pages

Статический сайт: видео-интро с 3D и текстом, регистрация по почте и паролю, лента постов, лайки, комментарии, жалобы, личные сообщения и модерация. Все данные хранятся онлайн в Firebase (бесплатный тариф Spark), сам сайт работает на GitHub Pages.

Модератор: аккаунт с подтверждённой почтой **tamshop.ru@gmail.com**. Он видит жалобы, удаляет посты и комментарии, блокирует участников и выдаёт синюю галочку. Это проверяет сервер (правила Firestore), а не страница, так что подделать нельзя.

## 1. Создайте проект Firebase (5 минут)

1. Откройте https://console.firebase.google.com и нажмите «Добавить проект». Google Analytics можно выключить.
2. Слева «Сборка» -> **Authentication** -> «Начать» -> вкладка «Способ входа» -> включите **Электронная почта/пароль**.
3. Слева «Сборка» -> **Firestore Database** -> «Создать базу данных» -> выберите регион (например, europe-west) -> режим «Рабочий» (production).
4. В Firestore откройте вкладку **Правила**, удалите всё, вставьте содержимое файла `firestore.rules` из этой папки и нажмите «Опубликовать».
5. «Настройки проекта» (шестерёнка) -> «Ваши приложения» -> значок `</>` (веб) -> зарегистрируйте приложение -> скопируйте блок `firebaseConfig`.
6. Откройте файл `firebase-config.js` и вставьте значения вместо `ВСТАВЬТЕ_...`.

## 2. Выложите на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него всё содержимое этой папки (файл `index.html` должен лежать в корне).
2. Репозиторий -> Settings -> Pages -> Source: «Deploy from a branch» -> ветка `main`, папка `/ (root)` -> Save.
3. Через минуту сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.
4. Вернитесь в Firebase -> Authentication -> Настройки -> **Авторизованные домены** -> «Добавить домен» -> `ВАШ_ЛОГИН.github.io`. Без этого вход не заработает.

## 3. Сделайте модератора

1. Откройте сайт, нажмите «Регистрация» и зарегистрируйтесь с почтой tamshop.ru@gmail.com.
2. Откройте письмо от Firebase, перейдите по ссылке, затем на сайте нажмите «Я подтвердил(а)».
3. Появится вкладка «Жалобы», а у участников в списке кнопки «Дать галочку» и «Заблокировать».

Чтобы поменять почту модератора, замените её в двух местах: `firebase-config.js` (MOD_EMAIL) и `firestore.rules` (функция isMod). Затем заново опубликуйте правила.

## Что важно знать

- Писать посты, ставить лайки и отправлять сообщения можно только после подтверждения почты. Это защищает от массовых фейковых аккаунтов.
- Личные сообщения читают только отправитель и получатель, остальным их не отдаёт сервер. Но они не зашифрованы, и владелец проекта Firebase технически видит их в консоли.
- Пароли хранит сам Firebase Authentication, на сайте и в базе их нет.
- Ключ `apiKey` в конфиге публичный по замыслу Firebase. Безопасность держится на правилах `firestore.rules`.
- Бесплатный тариф Spark ограничен по числу операций в день. Для небольшого сообщества этого хватает.
- Видео-кнопка «Скачать» записывает ролик прямо в браузере и работает в Chrome, Edge, Firefox и Safari 14.1+. Если запись не поддерживается, сохраняется картинка.
- Сайт работает в современных версиях Chrome, Edge, Firefox и Safari (примерно с 2021 года). Для старых браузеров интро показывается в упрощённом виде.

## Структура

```
index.html          страница
style.css           стили
intro.js            видео-интро (three.js) и запись видео
app.js              аккаунты, лента, сообщения, модерация
firebase-config.js  настройки Firebase
firestore.rules     правила безопасности базы
```
